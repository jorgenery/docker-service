## 🚀 COMEÇAR JÁ

```bash
# 1. Preparar
bash prepara.sh

# 2. Configurar
cp .env.example .env
nano .env  # Editar!

# 3. Iniciar
bash start.sh

# 4. Verificar
bash status.sh
```

Ou com Make:
```bash
make init    # Preparar
make setup   # Setup completo
make start   # Iniciar
```
